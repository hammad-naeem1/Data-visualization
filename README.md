# 📊 Python Data Visualization with Matplotlib & Seaborn

A structured repository documenting exploratory data analysis (EDA) techniques, statistical plotting, and custom figure styling using **Matplotlib** and **Seaborn**. This repo serves as a practical reference and code archive for transforming raw datasets into clear, publication-ready visual insights.

---

## 🎯 What's Inside

* **Distribution & Univariate Plots:** Histograms, Kernel Density Estimates (KDE), box plots, and violin plots to inspect data spread and outliers.
* **Relationship & Multivariate Plots:** Scatter plots, regression plots, pair plots, and joint plots to uncover feature correlations and group patterns.
* **Categorical Comparisons:** Grouped bar charts, count plots, and point plots for comparing discrete variables.
* **Matrices & Heatmaps:** Annotated correlation matrices and pivot-table heatmaps using custom diverging color palettes.
* **Custom Aesthetics:** Fine-tuning `matplotlib.rcParams` and Seaborn themes for clean typography, custom color palettes, grid styling, and high-DPI exports.

---

## 🛠️ Tech Stack

* **Python 3.x**
* **Matplotlib** — Low-level figure control, subplots, and custom styling
* **Seaborn** — High-level statistical data visualization
* **Pandas & NumPy** — Data cleaning, aggregation, and numerical preparation
* **Jupyter Notebook** — Interactive analysis and visual documentation
